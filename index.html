E-Commerce Plataform

Desarrollé una plataforma de e-commerce completa desde cero utilizando el stack MERN. La aplicación incluye un sistema de autenticación robusto, carrito de compras persistente, integración con Stripe para pagos seguros, y un panel de administración completo para gestionar productos, órdenes y usuarios.

Características principales:
  • Autenticación de usuarios con JWT
  • Carrito de compras con persistencia en base de datos
  • Pasarela de pagos Stripe integrada
  • Panel de administración completo
  • Sistema de búsqueda y filtros avanzados
  • Diseño responsive y accesible
React Node.js MongoDB Stripe Express

Task Manager App

Aplicación web moderna para gestión de tareas y proyectos inspirada en herramientas como Trello. Implementé funcionalidad de arrastrar y soltar usando React DND, sincronización en tiempo real con Firebase, y un diseño intuitivo con Material-UI.

Características principales:
  • Drag & drop entre columnas de estado
  • Sincronización en tiempo real
  • Categorías y etiquetas personalizables
  • Sistema de prioridades y fechas límite
  • Modo colaborativo (múltiples usuarios)
  • Dark mode integrado
React Firebase Real-time Material-UI

Weather Dashboard

Dashboard meteorológico interactivo que consume datos de la API de OpenWeather. Incluye visualización de datos con gráficos, mapas interactivos, y sistema de alertas para condiciones climáticas específicas. El proyecto demuestra habilidades en consumo de APIs, visualización de datos y diseño responsive.

Características principales:
  • Pronóstico extendido de 7 días
  • Datos en tiempo real de múltiples ciudades
  • Gráficos interactivos con Chart.js
  • Mapas de temperatura y precipitación
  • Sistema de alertas personalizables
  • Búsqueda por ubicación
JavaScript API Chart.js Vanilla JS

Portfolio Generator

Herramienta web que permite a desarrolladores y diseñadores crear portfolios profesionales sin escribir código. Los usuarios pueden elegir entre varios templates, personalizar colores y contenido, previsualizar en tiempo real, y exportar el código HTML/CSS completo.

Características principales:
  • 5 templates profesionales
  • Editor visual intuitivo
  • Previsualización en tiempo real
  • Personalización de colores y fuentes
  • Exportación de código limpio
  • Responsive por defecto
Vue.js Node.js CExpress SPA
